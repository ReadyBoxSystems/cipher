**New font loading (source: CONTEXT.md D-09):**


## Theme System Contract

Two themes. Each is a `[data-theme]` attribute on `<html>` that overrides CSS custom properties. No DOM structure changes between themes. (Source: CONTEXT.md D-05, D-06.)

**Theme application (boot, before router):**
```js
const savedTheme = localStorage.getItem('cipher-theme') || 'postdesk'
document.documentElement.dataset.theme = savedTheme
```

**Default theme for new users: `postdesk`.** (Source: CONTEXT.md D-15.)

| Attribute Value | Theme Name |
|----------------|------------|
| `postdesk` | Postdesk (warm parchment / postal) |
| `terminal` | Terminal (dark amber — existing, unchanged) |

## Spacing Scale

Established pattern from existing CSS — 4px grid throughout. Phase 4 adds no new spacing categories.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, checkbox gaps |
| sm | 8px | Compose meta gaps, panel row gaps, topbar side padding |
| md | 16px | Conversation row padding (horizontal), section content padding |
| lg | 24px | Section padding, auth screen gap, settings footer padding |
| xl | 32px | Invite body padding |
| 2xl | 48px | Avatar large size in settings header |
| 3xl | 64px | Not currently used — reserved |

**Exceptions:**
- Touch targets (icon buttons, avatar button): 44×44px minimum — enforced via `width: 44px; height: 44px` on `.icon-btn` (existing pattern, apply to inbox avatar button).
- Settings header avatar: 48×48px (slightly oversized for visual weight — existing pattern in `settings.js`).
- Theme swatch cards: minimum 44px tall for tap comfort.

## Typography

### Terminal Theme (existing — do not change)

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Timestamp / Meta | 9–10px | 400 | 1.4 | JetBrains Mono | Message times, conv times, footer version |
| Label / UI | 11px | 400 | 1.4 | JetBrains Mono | Section labels, tab text, btn text, lock label, error msg |
| Conv name / Field | 12–13px | 400 | 1.4–1.55 | JetBrains Mono | Conversation names, form fields, bubble text, compose input |
| Title / Logo | 11px | 400 | 1.0 | JetBrains Mono | Topbar title (letter-spacing: 0.3em), logo name (0.5em) |

Two weights in use: **400 regular** (all UI) and **500** (avatar initial only — `.avatar` existing).

### Postdesk Theme (new — overrides via `[data-theme="postdesk"]`)

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Timestamp / Meta | 9–10px | 400 | 1.4 | Special Elite | Message times, conv times |
| Label / UI | 11px | 400 | 1.4 | Special Elite | Section labels, tab text, btn text — typewriter feel |
| Body / Cipher text | 13px | 400 | 1.55 | Special Elite | Bubble text, form fields, cipher content |
| Screen Title / Display | 18px | 400 | 1.2 | Cormorant Garamond | Topbar title, screen headings, settings CIPHER header |

Two weights: **400 regular** (all text) and **600 semibold** (Cormorant Garamond for major display moments only — optional, use sparingly).

Letter-spacing in Postdesk: reduce or remove the existing generous letter-spacing on JetBrains Mono — Cormorant Garamond and Special Elite don't need tracking.

## Interaction Contract

### Theme Switch (THEME-03 — instant, no reload)

1. User taps a theme swatch card
2. Immediately: `document.documentElement.dataset.theme = '{theme}'`
3. Immediately: `localStorage.setItem('cipher-theme', '{theme}')`
4. Immediately: Update store `profile.theme` field
5. Async (no await): `transport.updateProfile(userId, { theme: '{theme}' })`
6. Immediately: Re-render swatch active state (update border class on both cards)
7. No page reload. No transition animation. CSS custom property override is instantaneous.

### Boot Theme Application (THEME-01, THEME-02)

- Runs in `app.js` before any router call
- `localStorage.getItem('cipher-theme') || 'postdesk'` — Postdesk is default
- Sets `document.documentElement.dataset.theme` synchronously
- On profile load from Supabase: if `profile.theme !== localStorage.getItem('cipher-theme')`, update localStorage and re-apply (cross-device sync — THEME-04)

### Avatar Button → Settings

- Tap the avatar initial in the inbox topbar
- `router.navigate('#/settings')` — no transition beyond the standard screen replace
- Back button in settings returns to `#/` (existing pattern)

### Display Name Edit (existing — no changes)

- Tap the Display name row → inline `<input>` appears
- Enter or blur → commit (optimistic) → silent rollback on error
- Escape → cancel, no change
