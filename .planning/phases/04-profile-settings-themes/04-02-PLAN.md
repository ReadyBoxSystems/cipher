<objective>
Wire the theme system at the boot/network layer so the CSS overrides from Plan 01 actually take effect on page load. Four files, all infrastructure:

1. `index.html` — add Google Fonts `<link>` tags for Cormorant Garamond and Special Elite (D-08, D-09).
2. `sw.js` — bump cache version, add Google Fonts CSS URL to ASSETS array (research Pitfall 3, D-09).
3. `app.js` — apply saved theme from localStorage BEFORE `transport.getSession()`; on profile load, sync `profile.theme` → localStorage if different (D-12, D-14, D-15, THEME-01, THEME-02).
4. `schema.sql` — document the `theme text default 'postdesk'` column on `profiles` (D-13). The live Supabase migration is run separately; this file is the source-of-truth doc.

This plan is independent of Plan 01 (different files) — runs parallel in Wave 1. Plan 04 (settings APPEARANCE wiring) consumes both.

Purpose: Without boot-time application, every page load would flash Terminal then switch to Postdesk. Without service worker caching, fonts fail offline. Without schema column, cross-device sync has no place to store the preference.
Output: App boots with saved theme already applied. Fonts cached. schema.sql documents profiles.theme.
</objective>
