  <action>
    Replace the body of the `createProfile` method in `transport/supabase-transport.js` (currently lines ~38-43). The current code is:

    ```javascript
    async createProfile(userId, username, displayName) {
      const { data, error } = await sb.from('profiles').insert({
        id: userId, username, display_name: displayName
      }).select().maybeSingle()
      return { result: data ?? null, error: error ?? null }
    }
    ```

    Replace it with:

    ```javascript
    async createProfile(userId, username, displayName) {
      const { data, error } = await sb.from('profiles')
        .upsert(
          { id: userId, username, display_name: displayName },
          { onConflict: 'id' }
        )
        .select()
        .maybeSingle()
      return { result: data ?? null, error: error ?? null }
    }
    ```

    Rationale: A stale auth session reuses the same `user.id`. With `.insert()`, Postgres raises `23505` on the primary key — the v0 known bug #1. With `.upsert({ onConflict: 'id' })`, the same id silently overwrites; only a duplicate `username` (different id) still raises `23505` on the `username` unique constraint, which the Setup screen will route to "handle taken" in Plan 02.

    Do NOT change any other method in this file. Do NOT change `interface.js` — the return shape `{ result, error }` is unchanged.

    Update the inline comment in `transport/interface.js` for `createProfile` from "Phase 2 will switch to upsert" to "Uses upsert with onConflict:'id' to survive stale sessions (PROF-02)." — change only the JSDoc text on the createProfile @property line, nothing else.

    ```javascript
    // getSession() returns { user } — null if signed out. We additionally load the
    // profile row so screens can read store.get('profile') without a per-mount fetch.
    // onAuthChange fires on sign-in AND sign-out — on null we MUST clear both keys
    // (Pitfall 4: profile would otherwise leak across user switches on the same device).
    transport.getSession().then(async ({ user }) => {
      store.set('user', user)
      if (user) {
        const { result: profile } = await transport.getProfile(user.id)
        store.set('profile', profile)
      }
      transport.onAuthChange(async (u) => {
        store.set('user', u)
        if (u) {
          const { result: profile } = await transport.getProfile(u.id)
          store.set('profile', profile)
        } else {
          store.set('profile', null)
        }
      })

      // ── Start router ───────────────────────────────────────────────────
      router.start()
      router.route()
    })
    ```
