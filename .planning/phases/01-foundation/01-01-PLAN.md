  <behavior>
    - encrypt('hello', 'pw') returns { payload, iv, salt } where all three are non-empty base64 strings
    - decrypt(payload, iv, salt, 'pw') returns 'hello' for the matching ciphertext
    - decrypt(payload, iv, salt, 'wrong') returns null (does NOT throw)
    - encrypt of a 5MB string ('A'.repeat(5_000_000)) completes without RangeError / stack overflow
    - encrypt('hi', '') rejects with an Error whose message includes 'passphrase' (no silent fallback)
    - encrypt('hi', null) rejects with an Error whose message includes 'passphrase'
    - encrypt('hi', undefined) rejects with an Error whose message includes 'passphrase'
    - Round-trip encrypt → decrypt of a 1MB payload returns the exact same string
  </behavior>
  <action>
    Make exactly these three changes to crypto.js:

    1. Replace the `toB64` function body. Current (BROKEN):
       ```javascript
       function toB64(buf) {
         return btoa(String.fromCharCode(...new Uint8Array(buf)))
       }
       ```
       New (REQUIRED — chunked loop, no spread):
       ```javascript
       function toB64(buf) {
         const bytes = new Uint8Array(buf)
         let binary = ''
         const CHUNK = 0x8000
         for (let i = 0; i < bytes.length; i += CHUNK) {
           binary += String.fromCharCode.apply(null, bytes.subarray(i, i + CHUNK))
         }
         return btoa(binary)
       }
       ```
       Rationale (per D-07 + Pitfall #4): `String.fromCharCode(...new Uint8Array(buf))` blows V8's argument-count stack limit (~125k args) on payloads over ~125 KB. The chunked loop is the canonical fix.

    2. At the top of `export async function encrypt(plaintext, passphrase)` (currently line 28), add a guard as the FIRST statement of the function body:
       ```javascript
       if (typeof passphrase !== 'string' || passphrase.length === 0) {
         throw new Error('encrypt: passphrase is required (empty/missing passphrase rejected)')
       }
       ```
       Rationale (per D-08 + Pitfall #5 + SEC-04): the v0 fallback `key || 'cipher'` silently encrypted blank-key sends with a publicly known string. There is no `|| 'cipher'` literal in crypto.js today (it lives in app.js's `_send`), but crypto.js must refuse to do anything with an empty key so that no caller — current or future — can silently weaken encryption.

    3. Add the same guard at the top of `export async function decrypt(payload, iv, salt, passphrase)` (currently line 41), as the first statement BEFORE the try/catch:
       ```javascript
       if (typeof passphrase !== 'string' || passphrase.length === 0) {
         throw new Error('decrypt: passphrase is required (empty/missing passphrase rejected)')
       }
       ```
       Note: this guard is OUTSIDE the try/catch on purpose — empty key is a programmer error, not a wrong-key event. Wrong key still returns null (existing catch behavior preserved).

    Do NOT change anything else: the PBKDF2 parameters (100000 iterations, SHA-256), the salt size (16 bytes), the IV size (12 bytes), the AES-GCM mode, or the export signatures. Those are SEC-01/SEC-02/SEC-03 contracts that the rest of the app and Phase 5 tests depend on.
  </action>

    Write sw.js with this exact content:

    ```javascript
    const CACHE = 'cipher-v2'
    const ASSETS = [
      './',
      './index.html',
      './style.css',
      './manifest.json',
      './app.js',
      './supabase.js',
      './crypto.js',
      './ciphers.js',
      './transport/index.js',
      './transport/interface.js',
      './transport/supabase-transport.js',
      './transport/mock-transport.js',
      './state/store.js',
      './lib/router.js',
      './lib/settings.js',
      './lib/utils.js'
    ]

    self.addEventListener('install', e => {
      e.waitUntil(caches.open(CACHE).then(c => c.addAll(ASSETS)).catch(() => {}))
      self.skipWaiting()
    })

    self.addEventListener('activate', e => {
      e.waitUntil(caches.keys().then(keys =>
        Promise.all(keys.filter(k => k !== CACHE).map(k => caches.delete(k)))
      ))
      self.clients.claim()
    })

    self.addEventListener('fetch', e => {
      if (e.request.method !== 'GET') return
      if (e.request.url.includes('supabase.co')) return // never cache API calls
      e.respondWith(
        caches.match(e.request).then(cached => cached || fetch(e.request))
      )
    })
    ```
